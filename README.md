# Economics Thesis — Optimal Penalty Decision

This repository contains the complete materials for my Economics Capstone thesis at Trinity College Dublin (2025–26).

The project develops a quantitative decision framework for evaluating penalty choices in rugby union using probabilistic modelling and simulation. The framework compares tactical decisions under multiple objectives, including win probability, expected league points, promotion probability, and survival probability. Economics_Thesis (16).pdf

## Thesis Overview

The thesis develops a structural decision framework that evaluates the choice between kicking at goal and kicking to the corner in rugby union. The framework integrates:

- A hierarchical goal-kicking model
- A stochastic model of attacking sequences following kicks to the corner
- A continuous-time Weibull competing hazards scoring model
- Season-level Monte Carlo league simulations

Together, these models estimate the value of each penalty decision under different objectives, demonstrating that strategies which maximise win probability are not always optimal once league incentives such as bonus points, promotion, and survival are considered. Economics_Thesis (16).pdf
